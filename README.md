Overview ✅
Barcode Reader is a small, mobile-first application built with React Native (Expo) that lets users scan barcodes and QR codes, store scan results locally, and manage saved scans. It includes a clean UI, theming utilities, and local persistence via SQLite.tsx.


Features ✨
Real-time barcode & QR code scanning
Save and delete scan history (local SQLite storage) 🔧
Themed UI with reusable components (components/*) and safe-area support
Cross-platform: iOS and Android (Expo) 📲
Small, modular codebase suitable for customization and learning
